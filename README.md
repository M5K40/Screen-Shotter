# Screen-Shotter BETA
Software that automatically takes screenshots of you desktop. Current .exe file may not work. This will be fixed ASAP!

## How To Download
Navigate to screenshotter.exe and download it.
Open the exe, it will give you a console to change the amount of MB and quantity of screenshots limit.

## Keybinds
Q To start and stop
Ctrl + C to quit the process

## Features
Custom Limit for screenshot Quantity
Custom Limit for screenshot MegaBytes
