# Screen-Shotter 
Software that automatically takes screenshots of you desktop. Current .exe file with no console currently works, same for screenshotterWGUI.

## How To Download
Navigate to screenshotter.exe and download it.
Open the exe, it will give you a console to change the required fields, most of the fields can be skipped with the "Enter" key, and they will be set to the default values stated in the console.

Navigate to screenshotter.exe and download it.
Open the exe, and a GUI will open will in the fields and start using with your own custom key binds and themes.

## Keybinds (Can be changed)
Q To start and stop
Ctrl + C to quit the process

## Features
Custom Limit for screenshot Quantity
Custom Limit for screenshot MegaBytes
